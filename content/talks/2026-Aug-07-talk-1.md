#### **Talk**
- **Topic:** Introduction to Separation Logic :: Part II

- **Description:** This workshop provides a gentle introduction to the core ideas behind Separation Logic and the IRIS Framework. Participants will learn how assertions about memory differ from classical Hoare Logic, understand the separating conjunction (*) and the frame rule, and see how these concepts dramatically simplify correctness proofs for programs operating on linked data structures.
