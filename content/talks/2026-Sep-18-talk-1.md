#### **Talk**
- **Topic:** 2026 Sep 11 :: Introduction to modes in OxCaml Part III

- **Description:** OCaml’s type system tells you the shape of a value — but not necessarily where it lives in memory, how many places still point to it, or whether it’s safe to touch from another thread at the same time. This talk introduces OxCaml’s mode system: a set of extra, independent checks the compiler layers on top of ordinary types to catch exactly these problems before the program ever runs — enabling faster memory management, safer mutation, and safe parallelism, all with zero runtime cost. We’ll build up the intuition behind each of these checks from simple examples, and see where these checks apply and where they don’t.
